Meu primeiro formulário

Em inputs, o "name" é mais útil para HTML e PHP, já o "id" é mais para JavaScript.

Método GET: dados não sensíveis. Até 3 mil bytes de dados (3000 letras). Sem envio de arquivos. Os dados vão a URL.

Método POST: dados sensíveis. Carecem de segurança. Mais de 3 mil bytes. Envio de arquivos. ESTUDAR HTTP E HTTPS. Os dados vão "escondidos" no corpo da requisição do http.

Atualmente, os métodos GET e POST não têm diferença significativa de velocidade.
