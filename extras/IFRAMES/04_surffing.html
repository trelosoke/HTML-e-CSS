Navegação dentro do iframe

É possível que o iframe tenha seu "alvo" de site mudado através de links:

Site 1 no iframe Site 2 no iframe

Para que o código acima funciona, um atributo name no iframe deve ser colocada. Pode ser qualquer nome: name="frame". Para conectar os links para o iframe, devemos colocar no target desses links o nome que colocamos no iframe: target="frame". Ao clicar em um dos links, a página é carregada diretamente no iframe.

Aqui está como o código do exemplo acima está estruturado:


    <a href="00_siteTeste1.html" target="frame">Site 1 no iframe</a>
    <a href="00_siteTeste2.html" target="frame">Site 2 no iframe</a>

    <iframe src="" name="frame"></iframe>
