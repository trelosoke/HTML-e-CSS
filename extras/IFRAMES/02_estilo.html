Estilos em um iframe

Tamanho

O tamanho padrão do iframe é de 300 píxeis de largura por 150 de altura. Porém, isso pode ser mudado no "inline" do iframe pelos atributos height e width.

Também é possível fazer isso dentro das CSS da página, o que substitui qualquer altura colocada no "inline" do iframe


    iframe {
        width: 350px;
        height: 200px;
    }

Rolagem

É possível configurar como a rolagem do iframe funcionará através do atributo scrolling(OBSOLETO). Há 3 configurações possíveis:

  • scrolling="auto"

      • Possibilita que o próprio atributo determine o que seja melhor (geralmente escolher ter rolagem quando o site é verticalmente maior do que a altura do iframe).

  • scrolling="yes"

      • Adiciona barra de rolagem, geralmente. Pode não funcionar.

  • scrolling="no"

      • Remove barra de rolagem.

Muito importante mencionar que essa forma está obsoleta. O melhor modo de fazer isso é utilizando as CSS, com a propriedade overflow, mas isso mais para frente.
