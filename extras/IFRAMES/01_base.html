O que é um iframe?

Um iframe ou "inline frame" é uma tag HTML que permite a inserção de páginas dentro de um bloco em um site, como no exemplo:

Nele pode haver algum texto dentro (com parágrafo, ou até um link) que aparecerá caso o iframe não funciona/não apareça.


    <iframe src="https://cursoemvideo.com" frameborder="0">
        <p>
            Texto aqui. Seu iframe não apareceu.
            <a href="https://cursoemvideo.com" target="_blank">link do iframe</a>
        </p>
    </iframe>

Ele tem dois atributos básicos chamados src(source), que determina qual página será exibida, e frameborder, que aceita "0" como não tendo borda e qualquer outro valor acima de 0 como tendo borda.

Permissão

Muitos sites não permitem adicioná-los como iframe (ao menos não de cara), como o Google. Isso porque os iframes tem um problema de segurança, o que poderia causar Clickjacking (colocar um iframe invisível para um outro site para "sequestrar" seu clique, podendo ser para excluir conta ou alterar senha). Também por problemas de layout, já que um site complexo como o Google não foi feito para rodar em janelas pequenas e limitadas de terceiros.
