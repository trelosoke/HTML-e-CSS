Exemplo de uso de position fixed

O elemento fica acima de todo o conteúdo do site, seguindo fixo no local escolhido e acompanhando o rolamento da página. As propriedades agora são relativas à viewport/tela do usuário.

O interessante agora é que podemos usar porcentagem para centralizar o elemento, nessa forma. Podém, precisamos mudar a origem do objeto, que se localiza no top-left dele. Para isso, "puxamos" o elemento 50% para a esquerda e para cima utilizando translate.
