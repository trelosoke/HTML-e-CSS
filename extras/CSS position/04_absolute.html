Child Element

Exemplo de uso de position absolute

Necessita de outro elemento com position (geralmente relative, já que o elemento permanece onde está), caso contrário, ele agirá de acordo com a tela, não com o elemento. O absolute fica com o elemento que eu quero que fique dentro de outro, que aja em relação a ele.

Por exemplo: o top: 0; e right: 0; no child element está fazendo isso em relação ao parent element.

Importante notar que os elementos absolutos vão sempre estár acima dos elementos do site, a não ser que haja uma forma de mudar isso...
