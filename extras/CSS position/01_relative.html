Exemplo de uso de position relative

Aqui, ao utilizar o relative e manipulá-lo, a página age como se o elemento ocupasse a posição e o espaço original que ele ocupava na criação. Então, quando ele for mudado de lugar, os outros elementos não vão se mexer para se adequar a ele. Tanto é que, no exemplo acima, o elemento está passando por cima de outro, mas a margem considerada é a do estado original do elemento.
